THE PROBLEM

Tesla research is easy to collect.
It is harder to trust.

Primary documents, biographies, archived pages, transcripts, and personal notes are often mixed together. This project keeps them searchable while preserving the distinctions that matter: provenance, evidence tier, extraction quality, and publishing rights.

01

Search the text directly

Readable UTF-8 exports retain page markers, making the collection easy to search with GitHub or rg without a database or proprietary reader.

02

Know what supports a claim

Sources are separated into primary evidence, strong scholarly context, secondary interpretation, and unverified research leads.

03

Preserve rights boundaries

Public-domain works stay distinct from research-only material, leads, and personal notes. Inclusion is never treated as publishing clearance.

04

Turn sources into models

The first browser-based model visualizes Tesla’s rotating magnetic field and the relationships among frequency, pole count, load, and slip.

INTERACTIVE MODEL 01

The AC induction motor

Two alternating currents, offset in time and space, combine into a magnetic field that turns. A conducting rotor follows without an electrical connection to the supply.

HOW IT WORKS

From collected file
to citable research.

The repository uses small Node.js scripts and plain files, keeping the archive inspectable and portable.

  1. 01

    Ingest

    Extract text from PDF, EPUB, HTML, Markdown, or text sources and record a checksum.

  2. 02

    Classify

    Assign evidence tier, rights state, visibility, extraction status, and stable identifiers.

  3. 03

    Export

    Write path-safe text files and catalog metadata without leaking machine-local paths.

  4. 04

    Validate

    Run integrity tests for catalog coverage, category separation, searchable content, and privacy.

RUN IT LOCALLY

No framework.
No database.
No build step.

Clone the repository, open the showcase or model in a browser, and use standard text tools to explore the archive. Node.js is required only for maintenance scripts and tests.

Read the documentation ↗ Open the source catalog ↗
terminal
$ git clone git@github.com:beejmaxx/tesla-research-library.git
$ cd tesla-research-library

# Search all tracked source text
$ rg -n -i 'rotating magnetic field' library/

# Validate the archive
$ node --test tests/library.test.mjs

# Preview this showcase
$ python3 -m http.server 4173 -d site

CURRENT STATUS

Useful now,
honest about its gaps.

Working archive

Catalog, exports, ingestion scripts, integrity checks, and the first interactive teaching model are present.

Rights review still matters

Research-only sources and third-party excerpts are not cleared for unrestricted redistribution.

Some extraction is incomplete

Two patent/interview scans have little embedded text or require OCR; Tier-D leads cannot support claims on their own.

Model series is beginning

The AC motor is Model 01. Other areas of Tesla’s work do not yet have interactive representations.
